FIORANO DATA FLOW (Trade Finance USSD)
================================================================================

INPUT: 
  - countryCode (e.g., KE)
  - phoneNumber (e.g., 254711111111)
  - nationalId OR passport (provided by user or USSD system)

PROCESS:
  1. Check Profile Service for existing profile
  2. If NOT found:
     a. Call FioranoDataQueryServiceImpl.getCustomerCoreBankingAccountsByIdNumberOrPassport()
     b. Pass: National ID or Passport
     c. Fiorano service queries: /query-customer-by-id or /query-customer-by-passport
     d. Returns: FioranoCustomerAccountStatusResponse with customer details
     e. Map response fields to Profile entity

OUTPUT PROFILE DATA FROM FIORANO:
  - firstName
  - lastName  
  - email
  - phone
  - idNumber (national ID)
  - idType (NATIONAL_ID or PASSPORT)
  - address
  - dateOfBirth
  - accounts (linked bank accounts)
  - customerStatus
  - CIF (Customer ID in core banking)

PROFILE CREATION:
  - Linked to Trade Finance tenant
  - Country: from input
  - Phone: from input
  - Device: trade-finance-ussd-{CC}-{PHONE}
  - Status: INCOMPLETE (onboarding not done)
  - Onboarding config: skipSecurityQuestions=true, skipCellulant=true
